# BrowserPair for Cursor

Let Cursor's agent work in your own signed-in Chrome. BrowserPair connects Cursor to the Chrome profile you already use, so the agent can open pages, read dashboards, fill forms and check results on the websites you are already signed in to, while you keep using your browser.

- **Your Chrome, your sessions:** no remote browser and no new logins.
- **Your approval:** Standard mode asks you in Chrome before sensitive steps such as signing in, paying, sending or deleting.
- **Verified results:** every result is checked on the page, and a step with an uncertain outcome is never repeated automatically.

## Setup

1. Create a BrowserPair account at [app.browserpair.com](https://app.browserpair.com/).
2. Install the [BrowserPair Chrome extension](https://chromewebstore.google.com/detail/agdomhjeahcbelohnmjmbldeldclnoof) and connect your Chrome in the app.
3. Install this plugin in Cursor, then sign in to BrowserPair when Cursor asks (OAuth).
4. Ask the agent, for example: *"Use BrowserPair to open our staging site, sign-in is already done, and check that the pricing page shows three plans."*

The plugin adds BrowserPair's hosted MCP server (`https://mcp.browserpair.com`), a short skill and a rule that tell the agent when and how to use it.
